Methodology notes

  • Subsidized baseline target is Opus-equivalent spend in the $3,000-$5,000 range against the Max plan list price.
  • Pressure ratio = (model monthly cost / Max plan cost) / (model intelligence / Opus intelligence).
  • Lower pressure ratio is stronger: 1.0x means near-Max-plan cost at Opus-level intelligence.
  • Flagship rows use Feb 2026 reference monthly cost values from the provided chart.
  • Pressure value uses an intelligence gate (must exceed 90% of Opus) multiplied by an exponential cost penalty from pressure ratio.
  • Table is sorted by pressure value descending, with the Opus baseline pinned to the first row.
  • SWE-Bench remains visible as the direct coding benchmark.
  • Intelligence score = weighted average (SWE 25%, Long Horizon 15%, AIME 20%, GPQA 15%, LiveCodeBench 25%).
  • Cost per intelligence point = monthly cost / intelligence score.
